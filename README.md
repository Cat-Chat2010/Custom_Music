Повноцінний клієнтський мод для **Minecraft 1.21.1**, який розширює стандартну систему фонової музики: дозволяє додавати власні аудіотреки будь-якого формату, налаштовувати чергу, затримку тиші та керувати відтворенням прямо в грі через зручне меню.

---

## ✨ Основні можливості

* 📥 **Автоконвертація аудіо (FFmpeg):** Закидайте аудіо будь-якого популярного формату (`.mp3`, `.wav`, `.flac`, `.m4a`, `.aac`, `.opus`, `.ogg`) в папку `import/`. Мод автоматично перетворює їх на оптимізовані `.ogg` (Vorbis 44.1 kHz Stereo) і видаляє оригінали.
* ⚡ **Динамічний ресурс-пак:** Аудіотреки стрімяться напряму з диска з папки `tracks/` через віртуальний ресурс-пак, що не забиває оперативну пам'ять (RAM).
* 🔀 **Режими відтворення:**
  * **Випадково (RANDOM):** Випадковий вибір треку зі списку активних (без повторів підряд).
  * **По порядку (SEQUENTIAL):** Суворе відтворення композицій за порядком, встановленим гравцем.
* ⏱️ **Гнучкі затримки тиші:** Можливість налаштувати мінімальну та максимальну паузу між треками (у секундах).
* 🎛️ **Керування плейлистом (GUI):**
  * Вмикання/вимикання як кастомних, так і ванільних треків гри.
  * Зміна позиції треку в черзі кнопками `▲` / `▼`.
  * Безповоротне видалення кастомного файлу з диска кнопкою `✕`.
  * Кнопка швидкого переходу на наступний трек `⏭`.
  * Кнопка «Імпортувати треки» прямо в меню гри без перезапуску.
* 💾 **Збереження конфігурації:** Усі налаштування та черга зберігаються у зручному `custom_music/settings.json`.

## 📂 Структура папок мода

При першому запуску мод автоматично створює папку `custom_music` у кореневій директорії гри:

```text
.minecraft/ (або корінь інстансу)
└── custom_music/
    ├── import/        <-- Сюди кидаємо аудіо будь-якого формату (.mp3, .wav тощо)
    ├── tracks/        <-- Тут зберігаються готові до гри .ogg треки
    ├── ffmpeg/        <-- Сюди можна покласти ffmpeg.exe (якщо немає в системному PATH)
    └── settings.json  <-- Файл конфігурації та збереженого порядку треків
```

## 🛠️ Налаштування FFmpeg

Для конвертації аудіо потрібен `FFmpeg`:
1. **Варіант 1 (Рекомендований):** Завантажте `ffmpeg.exe` з офіційного сайту ([ffmpeg.org](https://ffmpeg.org/download.html)) та покладіть його у папку `custom_music/ffmpeg/ffmpeg.exe`.
2. **Варіант 2:** Встановіть FFmpeg у системну змінну `PATH` вашої ОС.

> *Примітка:* Якщо ви додаєте треки у форматі `.ogg`, вони працюють **повністю без FFmpeg**! Навіть якщо ви закинете `.ogg` у папку `custom_music/import/` або оберете через кнопку «Додати музику» в грі, мод автоматично та безпечно перенесе їх у список треків без жодної конвертації.

## 🎮 Як користуватися в грі

1. Запустіть гру з модом.
2. Перейдіть у **Налаштування** ➔ **Налаштування звуку...** (Music & Sounds) або натисніть `Ctrl + P`.
3. Натисніть кнопку **🎵 Кастомна музика...**.
4. У відкритому меню ви можете:
   * Натиснути **Додати музику** для швидкого вибору аудіофайлів через провідник Windows.
   * Натиснути **Імпортувати треки** для обробки файлів з папки `import/`.
   * Перемикати режим: `Випадково / По порядку`.
   * Налаштувати повзунками **Мін. затримку** та **Макс. затримку** між мелодіями.
   * Вимикати непотрібні треки перемикачем `✓ Вкл / ✕ Вимк`.
   * Впорядковувати чергу Drag-and-Drop або стрілками.

## 🔨 Збірка проєкту з вихідного коду

### Вимоги:
* **JDK 21** (для запуску та компіляції)
* **Інтернет-з'єднання:** потрібне **тільки при першому запуску** (для завантаження залежностей Gradle, NeoForge та мапінгів Minecraft). Надалі мод та збірка працюють повністю автономно (офлайн).

### Команди:

1. **Клонування репозиторію:**
   ```bash
   git clone https://github.com/Cat-Chat2010/Minecraft-music.git
   cd Minecraft-music
   ```

2. **Збірка .jar файлу мода:**
   * **Windows:**
     ```cmd
     gradlew.bat build
     ```
   * **Linux / macOS:**
     ```bash
     chmod +x gradlew
     ./gradlew build
     ```
   Готовий `.jar` файл буде знаходитися в папці `build/libs/`.

3. **Тестовий запуск клієнта гри для розробки:**
   ```cmd
   gradlew.bat runClient
   ```
